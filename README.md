## Setup Instructions

To set up and run this project locally, follow these steps:

### 1. Clone the Repository
Clone or download this repository to your local computer:
```bash
git clone https://github.com/giuliamanco/Lintora_takehome.git
cd Lintora_takehome
```

### 2. Download the Dataset
Download the data archive (`lintora_dataset.zip`) here.

### 3. Extract the Data
Extract the contents of the downloaded `lintora_dataset.zip` directly into the empty `product/` directory of this project. Ensure files like `events.csv` and `users.csv` sit directly inside `product/`.

### 4. Run the Scripts
Once the data is in place, you can execute the Python scripts normally:
```bash
python analysis.py
python Classificator.py
```
*Note: Any new plots or updated graphics generated by running the code will automatically save into the `figures/` directory.*
